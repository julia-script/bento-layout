---
title: Grid Tracks
description: Sizing the rows and columns of a grid.
---

A grid's columns and rows are defined by track lists. Each track gets a minimum
and a maximum size, and CSS's single-value forms are shorthands for a pair.

## Fixed, flexible, and intrinsic

`120px` is a fixed track. `1fr` divides whatever space is left after the fixed
tracks are placed — proportionally, so `2fr` takes twice as much as `1fr`.

<Demo height={200}>
{`<Layout>
  <Node style={{display: 'grid', width: '440px', height: '120px',
                gridTemplateColumns: '120px 1fr 2fr', gap: '8px'}}>
    <Node />
    <Node />
    <Node />
  </Node>
</Layout>`}
</Demo>

Try changing `2fr` to `1fr` — the last two columns become equal.

## repeat()

`repeat(n, …)` expands to `n` copies of the tracks that follow it. `'auto-fill'`
fits as many as the container allows instead of a fixed count, which needs a
definite container width to have anything to fill.

<Demo height={220}>
{`<Layout>
  <Node style={{display: 'grid', width: '440px', height: '160px',
                gridTemplateColumns: 'repeat(auto-fill, minmax(100px, 1fr))',
                gridTemplateRows: 'repeat(2, 1fr)',
                gap: '8px'}}>
    <Node />
    <Node />
    <Node />
    <Node />
    <Node />
    <Node />
  </Node>
</Layout>`}
</Demo>

## minmax() and spanning

`minmax(a, b)` states the two bounds directly. An item can also cover several
tracks with `gridRowEnd: 'span 2'` or a line number.

<Demo height={220}>
{`<Layout>
  <Node style={{display: 'grid', width: '440px', height: '160px',
                gridTemplateColumns: 'minmax(140px, 1fr) 1fr 1fr',
                gridTemplateRows: '1fr 1fr',
                gap: '8px'}}>
    <Node style={{gridRowEnd: 'span 2'}} />
    <Node />
    <Node style={{gridColumnEnd: 'span 2'}} />
  </Node>
</Layout>`}
</Demo>

## In your own code

Track strings are a convenience of these demos. The library takes the pairs
directly — a single-value CSS track sets both bounds, except that `fr` and
`fit-content` tracks take an `auto` minimum:

```typescript
LayoutNode.make({
  display: 'grid',
  gridTemplateColumns: [
    { min: 120, max: 120 },                  // 120px
    { min: 'auto', max: { fr: 1 } },         // 1fr
    { min: 140, max: { fr: 1 } },            // minmax(140px, 1fr)
    { repeat: 'auto-fill', tracks: [{ min: 100, max: { fr: 1 } }] },
  ],
});
```
