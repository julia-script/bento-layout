---
title: Block Layout
description: Normal flow — stacked boxes and collapsing margins.
---

`display: 'block'` lays children out in normal flow: each box takes the full
inline size available and stacks below the previous one.

Note that the engine's default `display` is `'flex'`, not `'block'` as CSS would
have it, so a block box says so explicitly.

<Demo height={220}>
{`<Layout>
  <Node style={{display: 'block', width: '380px'}}>
    <Node style={{display: 'block', height: '40px'}} />
    <Node style={{display: 'block', height: '60px'}} />
    <Node style={{display: 'block', height: '40px'}} />
  </Node>
</Layout>`}
</Demo>

The container has no stated height — it grows to fit the stack.

## Collapsing margins

Adjacent vertical margins in normal flow collapse to the larger of the two,
rather than adding. The gap between these two boxes is 40px, not 60px.

<Demo height={220}>
{`<Layout>
  <Node style={{display: 'block', width: '380px'}}>
    <Node style={{display: 'block', height: '50px', marginBottom: '40px'}} />
    <Node style={{display: 'block', height: '50px', marginTop: '20px'}} />
  </Node>
</Layout>`}
</Demo>

Padding or a border on the parent's edge stops the collapse, as does
`overflow: 'hidden'`, which establishes a new block formatting context.

<Demo height={240}>
{`<Layout>
  <Node style={{display: 'block', width: '380px', overflow: 'hidden',
                padding: {top: '10px', bottom: '10px'}}}>
    <Node style={{display: 'block', height: '50px', marginBottom: '40px'}} />
    <Node style={{display: 'block', height: '50px', marginTop: '20px'}} />
  </Node>
</Layout>`}
</Demo>

## Percentages

A percentage length resolves against the containing block. Demos write them as
CSS strings; the library takes fractions, so `'50%'` is `{ percent: 0.5 }` —
note the 0–1 scale, since `{ percent: 50 }` would mean 5000%.

<Demo height={200}>
{`<Layout>
  <Node style={{display: 'block', width: '380px', height: '120px'}}>
    <Node style={{display: 'block', width: '50%', height: '40px'}} />
    <Node style={{display: 'block', width: '25%', height: '40px'}} />
  </Node>
</Layout>`}
</Demo>
